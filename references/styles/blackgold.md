# 画风卡 · 黑金夜路（blackgold）

**一句话**：深夜黑金极简线条插画。一个戴红围巾的剪影小人站在两排路灯延伸的夜路上，中间穿插金线数据图、羊皮纸卡和金箔大字。
**适合**：心理学、认知偏差、人生选择、社会现象、哲学；不知道选什么时的默认。情绪向选题（亲情、时间）也用它。
**作品**：《三门问题》《十二平均律》《谁陪你走得最久》《聚光灯效应》《表扬没用，批评有效？》《傅里叶级数画一只猫》。

## 色板与字体
- 底 #0B0906（暖棕中心光 + 暗角 + 静态噪点）；暖金 #E8B15A → #F6D79A；高亮 #F0C373；暗红 #B8322A（围巾、印章、负面点；负面字 #D0574C）。只有这几种颜色，不用蓝紫、不用霓虹。
- 中文：Noto Serif CJK SC（大字 900，字幕 700）；英文与数字：Cormorant Garamond。
- 光晕开着：亮的东西都会发光。大面积亮色（羊皮纸卡）用 `panel()`，它画在不加光晕的层上。

## 专属母题
| 函数 | 说明 |
|---|---|
| `road(c, t, o)` | 透视夜路。`o.cam` 前进距离（`lt * 1.2` = 往前走）；`o.vg` 消失点光；`o.lamp(L)` 每盏灯亮度（逐盏点亮/熄灭）；`o.rise(L)` 路灯升空成星（片尾用） |
| `figure(c, x, y, h, t, o)` | 剪影小人：纯黑、无五官、红围巾、淡金轮廓光、背对镜头。`o.lantern` 提灯亮度，`o.elder` 不戴围巾的长辈，`o.a` 透明度，`o.pool` 脚下光圈 |
| `goldText(c, s, x, y, size, a, t, o)` | 金箔大字（`bigWord` 就是它）：渐变 + 发光 + 移动扫光 |
| `burst(c, x, y, k)` | 径向光爆，大字出现时配一次 |
| `sparkles(c, seed, cx, cy, w, h, n, t, a)` | 飘浮的金色光点 |
| `starfield(c, t, a)` | 星空 |
| `glowDot(c, x, y, r, a, halo)` | 发光点 |
| `parchment(c, x, y, w, h, a, fn, o)` | 羊皮纸卡（`panel` 就是它）；`o.dark` 暗色卡 |

## HUD（可选）
`window.HUD = { s7: ['1990 · 美国', 'Parade · Ask Marilyn'] }`：右上两行小字（地点·年份 / 出处），交代可信度。

## 镜头基调
夜路场景 `in` 缓推或 `drift`；网格、数据图 `still`；片名卡交给主题（光爆 + 缩放已经是重音）。主场景（夜路 + 小人）短版至少出现 2 次：开头或"放进人生"一次，结尾一次（提灯）。

## 片名卡 / 片尾
片名卡：金箔大字从 1.12 缩到 1 + 光爆 + 光点 + 金线 + 宽字距英文。片尾：星空 + 路灯升空成星 + 金箔片名 + 英文 + 署名 + 一句话 + 出处。

## 坑
- 大量重复的亮色小元素（信封、上千个点）透明度压到 0.5，或 `grid(..., {plain: true, dimA: .12})`，否则光晕糊成一片。
- 卡片上的字、印章要画在 `panel()` 的回调里，否则会被卡片盖住。
- 自己加光源时别把画面"洗白"：近处路灯已经按距离压过亮度。
