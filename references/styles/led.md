# 画风卡 · 赌场记录牌（led）

**一句话**：深夜赌场里的 LED 记录牌。近黑底铺满灯珠网格，大字和数字都由一颗颗灯珠组成；红和白记录结果，荧光绿专门用来标"真相"。
**适合**：赌徒谬误、彩票、连胜连败、热手效应、随机与规律、大数定律，任何"计数 / 记录 / 押注"的选题。
**作品**：《赌徒谬误》（1913 年蒙特卡洛连开 26 次黑）。

## 色板与字体
- 底 #0C0C0D + 灯珠网格；红 #FF3B3B（红格 / 负面）；骨白 #EDE8DF（主文字 / 白格）；荧光绿 #3DFF8A（只给"真相"：正确答案、理论值）。
- 大字与数字：点阵（任何文字都会被光栅化成灯珠）；字幕：Noto Sans CJK SC；标签：等宽字体。
- 光晕开着（灯珠会发光）。

## 专属母题
| 函数 | 说明 |
|---|---|
| `ledText(c, s, x, y, size, color, a, o)` | 点阵字：`o.k` 从左往右点亮进度、`o.rows` 灯珠行数、`o.align`、`o.heavy` |
| `lamp(c, x, y, r, color, on, hollow)` | 单颗灯珠（on=0 是熄灭的暗珠） |
| `grid` 的点样式 | 1 = 绿、2 = 红、3 = 骨白空心、4 = 骨白实心、0 = 熄灭的暗珠 |
| `panel` | 深色点阵屏：双层细框 + 等宽小标题（`o.head`） |
| `barFill` | 柱子由灯珠堆成 |

## HUD
左上两行等宽字：`window.HUD = { s1: ['TABLE 07', 'SPIN #0027'], s5: ['SPINS', '1,000,000', 'accent'] }`（第三项是第二行颜色）。章节标记在右上。

## 镜头基调
记录牌、点阵屏 `still`；揭晓理论值用 `snap`；长龙记录可以 `drift`。前半 still，高潮前后才用快镜头。

## 片名卡 / 片尾
片名卡：一块点阵屏，片名从左往右逐列亮起，绿色英文跟着亮。片尾：点阵片名 + 绿色英文 + 一句话 + 署名（红）+ 出处。

## 坑
- `ledText` 按字符串缓存位图，同一字符串换字号会重新光栅化；动画缩放用 `c.scale`。
- 绿色是"真相色"，前半段别用，留给揭晓。
- 灯珠网格背景已经很满，不要再铺第二层纹理。
