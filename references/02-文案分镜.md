# 02 · 文案分镜

## 短版叙事骨架（默认，按 65 秒计）

| # | 段落 | 时长 | 作用 | 常用画面 |
|---|---|---|---|---|
| 1 | 演示式钩子 | 0–8s | 第 0 秒就把场景和问题摆出来，让观众先下注 | 门、登记单、记录牌、选项 A/B/C；问号大字 |
| 2 | 直觉答案 | ~5s | 说出大多数人的直觉（之后会被推翻） | 50/50 天平、投票条、对话框（随后被划掉） |
| 3 | **片名卡** | ~3s | 全屏大字 + 英文，对齐第一个鼓点（≤17.4s） | 主题自带片名卡（不写 SCN 就自动用） |
| 4 | 来历与冲突 | ~10s | 年份 + 人物 + 真实争议 | 期刊卡、信封堆、计数器、HUD 年份 |
| 5 | 模拟证明 | ~8s | 让数字动起来：上千次模拟、胜率滚动 | 点阵、计数器、进度条、折线 |
| 6 | 直观解释 | ~8s | 用一个图讲清机制 | 分组框、连线、公式逐行 |
| 7 | 极端化 | ~6s | 把参数推到极端（100 扇门、1000 人），一眼就懂 | 网格逐个熄灭 |
| 8 | 放进人生（安静段） | ~6s | 一句可以截图的话；配乐自动降下来 | 主场景（黑金：夜路 + 小人；记录牌：长龙记录牌） |
| 9 | 反转 / 高潮 | ~4s | 名人被说服、前提反转、结论一句话；白闪 | `CLIMAX` 场景 |
| 10 | 回到观众 + 片尾 | ~10s | 站队提问 + 评论区；片尾标题卡 5 秒 | 主场景 + 自动片尾 |

长版（2 分钟以上，只在用户要求时做）：钩子 → 提出问题 → 片名卡 → 来历与证明 → 放进人生 → 名人/典故反转 → 承认局限 → 情绪升华 → 高潮白闪 → 回到主场景和片尾。主场景至少出现 2 次（短版）或 4 次（长版）。


## 字幕规则

- 每句中文 ≤18 字（竖屏最多 20，横屏 26）；太长就拆，用破折号、逗号制造停顿。
- 每句配一行简洁英文（不是逐字直译，读起来像英文）。用户不要英文就留空字符串。
- 每段用【】标 1–2 个高亮词（显示为画风强调色），〖〗标否定/错误词（显示为负面色）。
- 句子显示时长 d = clamp(1.3 + 0.12 × 字数, 2.2, 3.6) 秒；关键句可以多给 0.3。
- 字幕里的数字 = 画面上的数字 = 模拟跑出来的数字。

## 分镜确认表（发给用户的格式）

表头一行：`画风：黑金夜路（blackgold）｜竖屏 1080×1920｜预计 1:08｜片名卡 9.1s｜高潮 48.3s`

| 段落 | 时间码 | 画面 | 中文字幕 | English |
|---|---|---|---|---|
| 钩子 | 0.0–2.1 | 一张生日登记单，365 格；人一个个进门，他的生日亮红 | 一个房间，要几个人—— | A room. How many people — |
| … | … | … | … | … |

"画面"一列必须写出**具体的物 + 它在做什么**（名词 + 动词），写不出就说明这一句还没想好。

表后附：片名（中文 + 英文）、事实来源（带链接）、自己补写或解读的内容、发布建议（标题、封面字、置顶评论）。

## 算时间码

先把文案写进片子目录的 `script.js`（只是数据，不算写代码），然后：

```sh
node tools/timecode.mjs            # 每句起止、片名卡和高潮时间、总片长（与引擎算法一致）
```

引擎的时间算法：句子真实显示 = 时长 × 0.93；句间 0.15s；换场景 +0.4s 再加该场景的 `LEAD`；最后一句后 +0.8s 进片尾标题卡（`TITLE_DUR`，默认 5s）。实测：8 句 ≈ 30s，20 句 ≈ 1:08，26 句 ≈ 1:25。

调整技巧：片名卡太晚 → 把钩子压到 2–3 句、减少 LEAD；高潮离片名卡太近（<6s）→ 配乐不会有安静段，往后挪；总长超了 → 先删"直观解释"里重复的话，不删证明。

## script.js 格式

```js
window.FILM = {
  title: '生日悖论', en: 'THE BIRTHDAY PARADOX',
  sub: '不是你和谁撞，是任意两个人撞',   // 片尾一句话：指向机制，不复述标题
  sign: '',                               // 署名，留空不显示
  style: 'blackgold',                     // blackgold 黑金夜路 / led 赌场记录牌
  aspect: 'vertical',                     // vertical 1080×1920 / horizontal 1920×1080
  refs: ['BBC News Magazine, 2014-06 …', '模拟：10,000 次，种子 23'],   // 片尾出处
  credit: '画面 · 文案 · 配乐 全部由代码生成',
};
window.LINES = [                          // [场景id, 时长秒, 中文, English]；场景顺序 = 第一次出现的顺序
  ['s1', 2.3, '一个房间，要几个人——', 'A room. How many people —'],
  ['s3', 2.4, '答案是：【23】个。', 'The answer: 23.'],
];
window.LEAD = { s1: 0, s2: .2 };          // 场景开头留白；s1 必须是 0
window.TITLE_DUR = 5;                     // 片尾标题卡时长
window.CARD = 's3';                       // 片名卡场景（不写 SCN.s3 就用主题自带的片名卡）= 第一个鼓点
window.CLIMAX = 's8';                     // 高潮场景：白闪 + 第二个鼓点（可省略）
window.FLASH = ['s3+0.4'];                // 可选：自定义白闪时间点（默认只在 CLIMAX）
window.CAM = { s1: 'in', s4: 'still', s5: 'out', s6: 'drift', s8: 'snap' };
window.CHAPTERS = { s1: '01 · 一个房间' };  // 左上章节标记（可省略）
window.HUD = { s1: ['2014', '巴西 · 世界杯'] };   // 常驻信息，格式见画风卡
window.SFX = [['s4', .2, 'tick'], ['s5', .3, 'whoosh']];   // 额外音效：[场景, 偏移秒, 种类, 音量]
```

音效种类：`tick click whoosh boom pop ding beep stamp drum type tap riser`。场景切换的 whoosh、片名卡和白闪的 boom、片尾的 chime 会自动加。
