# 04 · 配乐与音效

## 默认：原创合成配乐（`tools/music.py`）

```sh
python3 tools/music.py            # 读 timeline.json，按 FILM.style 选预设 → score.wav（已做响度）
```

只依赖 numpy + ffmpeg，几秒出结果，没有版权问题。曲子是按时间轴"写"出来的，所以鼓点天然准：

| 段落 | 时间 | 内容 |
|---|---|---|
| 开场 | 0 → 片名卡前一小节 | 第 0 秒就有低音、铺底和动机（不从安静慢慢起） |
| 抽空 | 片名卡前一小节 | 鼓和动机撤掉，只留低音 + 上升音 |
| **第一个鼓点** | 片名卡（`CARD` 场景开头 +0.12s） | 满编：底鼓、拍手、低音八分律动 |
| 安静段 | 高潮前 4–8 秒 | 只留铺底和稀疏动机（放可以截图的那句） |
| **第二个鼓点** | 高潮（`CLIMAX` 场景开头 +0.25s，白闪） | 更满：加踩镲、动机翻高八度 |
| 片尾 | 片尾标题卡起 | 只留铺底和动机，最后 2.2 秒淡出 |

| 预设 | 速度/调 | 配器 | 签名声 |
|---|---|---|---|
| blackgold | 112 BPM F 小调 | 低频八分律动、铺底、拨弦动机、底鼓拍手 | — |
| led | 107 BPM A 小调 | 拨弦动机、底鼓拍手踩镲 | 轮盘小球"哒" |

响度：两遍 loudnorm 到 -14 LUFS、4 倍过采样限幅；AAC 编码后成片一般 -15 LUFS、真峰值 -1 到 -2 dBTP。`gate.py` 会再查一遍。

改曲子：`music.py` 顶部 `PRESETS` 里改 `bpm`、`chords`（MIDI 根音 + m/M，每个和弦两小节）、`lead`（pluck / piano）。

## 音效

自动：场景切换 whoosh（轻）、片名卡 boom、白闪前 riser + boom、片尾 chime。
手动：`window.SFX = [['s4', .2, 'tick'], …]`，种类 `tick click whoosh boom pop ding beep stamp drum type tap riser`，第 4 项是音量倍数。印章落下配 `stamp`，数字定格配 `pop`，揭晓配 `ding`。别每句都加，一支片子 5–10 个手动音效足够。

## 用自己的背景音乐（`tools/bgm_mix.py`）

1. 找曲子参数：`python3 tools/bgm_mix.py --bgm 曲子.mp3 --analyze` 打印每 0.5 秒的能量条，满编进来的那一下就是鼓点；BPM 用任意测速工具或数拍子。
2. `python3 tools/music.py --sfx-only` 只出音效。
3. `python3 tools/bgm_mix.py --bgm 曲子.mp3 --bpm 112.3 --drop1 17.43 --drop2 102.51` → score.wav。曲子从 (drop1 − 片名卡) 处开始；两个鼓点之间剪掉或重复整小节，让 drop2 落在高潮上，打印误差。误差 > 0.3s 就调高潮前一个场景的 LEAD（LEAD 增加 x 秒，误差约减少 x 秒）再重跑。片名卡要早于曲子的 drop1。
4. `bash tools/make.sh --bgm`（跳过合成配乐）。

已知参数：《We Never (Remix)》112.3 BPM、F 小调，drop1 17.43s、drop2 102.51s，降调段 10.8–17.4s 与 86–102.5s，168s 后淡出。

版权：别人的曲子只用在你有权使用的地方。发抖音最稳的做法是导出一版只有音效的（或原创配乐版），在平台曲库里加同一首热门曲。
