# 05 · 封面（同一套骨架，两种配色）

每支片子单独做一张竖屏封面（1080×1920，同时出 2160×3840）。单独看是一张海报，并排放是同一个系列。**要害是「一张一个手法」**：骨架（底色、强调色、行位、细线、署名）永远不动，每张只换一处和标题语义直接相关的手法。换多了就散，一处不换就成了模板。

```sh
node cover/cover.mjs cover_spec.json <片名>_抖音封面   # 打印每行宽度、压字、副标越界；problems 不为空就改
```

## 0. 先定问题，不给答案
封面字只放**问题或冲突**（「几个人撞生日？」「换不换」「阳性≠得病？」），不放答案（「23 人」「1 占三成」）。原作者的后台：只有封面是问题的那支破了万。

## 1. 找题眼（三选一）
- **钩子词**：整句最扎眼的词（「骗子」「错觉」「换」），决定谁大谁小。
- **张力对**：互为极端的两头（最坏 ↔ 最亲），决定版式是否对称。
- **格式巧合**：同一个数字、同一个字、字数和主题对应（「换不换」三个字 = 三扇门）。最值钱，不用额外画图就成立。
找不到时用最常见的「副行 + 主行」两行加主次字号，不要硬造手法。

## 2. 定分行
- 一个词、≤4 字 → 单行满幅（字号 ≈ 888 ÷ 字数）或 2+2。
- 名词短语 3–6 字 → 「主体 + 后缀」，后缀降一档字号。
- 一句话 >8 字 → 两到三行，重量压在最后一行。
- 常用：副行 168（lh 196，y 452 起，字距 -2），主行 210–288（lh 340，y 640–660）。主行宽度 = 字数 × (字号 + 字距) ≤ 888。

## 3. 定一个手法
只选一个，且必须能用题眼解释：某一字降到 40% 透明、数字换强调色放大（segments 混排）、字外加细框、某行 `fade_right` 渐隐、分隔线换成 `broken` / `ticks`、`extra` 里画一个和题眼有关的小图形（三个门框、两道杠）。说不出理由的就是装饰，删掉。

## 4. 定光
光跟着「被照亮的是什么」走：整张被照亮 → 大径向光（1600×1600，peak 0.26）；只照某一行 → 光压在那行后面；光在字之间 → 极扁的椭圆夹在两行中间。不要把光打在空地上。记录牌（led）的绿光很冲，peak 降到 0.12–0.16。

## spec 速查

```json
{
  "style": "blackgold",
  "glow": [{"x": -160, "y": 500, "w": 1400, "h": 680, "peak": 0.24}],
  "title": [
    {"text": "三门问题", "size": 168, "lh": 196, "y": 452, "tracking": -2, "color": "cream"},
    {"segments": [{"text": "换不换", "size": 250, "color": "gold", "charOpacity": [1, 0.42, 1]}], "lh": 340, "y": 660, "tracking": 46}
  ],
  "extra": "for (let i = 0; i < 3; i++) { const cx = 221 + i * 296; c.save(); c.globalAlpha = .5; c.strokeStyle = C.line; c.lineWidth = 2; c.strokeRect(cx - 125, 672, 250, 330); c.restore(); }",
  "en": {"text": "THE MONTY HALL PROBLEM", "y": 1066},
  "divider": {"kind": "solid", "y": 1176},
  "sub": {"text": "近千名博士说「不用换」\n可换门的胜率是三分之二", "y": 1228},
  "sign": {"text": "YOUR NAME"}
}
```
- `color`：`cream` `gold` `line` 或 `#hex`；行和片段都可加 `opacity`；`charOpacity` 按字设透明度；`fade: "fade_right"` 一行向右渐隐。
- 混排字号用 `segments`（例：「凌晨」180 +「3」250 金色 +「点」250），自动对齐基线。
- `divider.kind`：`solid` / `broken` / `ticks`（配 `count`）/ `none`。`extra` 是一段 JS（参数 `c, S, C, rule`），画唯一的手法图形。
- 第 i 个字的中心 x = 96 + size/2 + i × (size + tracking)。加框时框宽不超过 size，框边不越过 x96。

## 交付封面时说三件事
1. 这张的取舍：题眼是什么、为什么这样分行、光为什么在那儿。
2. 一两个方向明确的备选（「想更狠就把某字压到 40%」）。
3. 系列关系：用了哪种手法，和前几张差在哪。

## 文案
- 英文小标用学科术语，不直译（社会比较 `SOCIAL COMPARISON`，基础比率谬误 `BASE RATE FALLACY`）。
- 副标是一句转折或反常识的短句，指向机制，不复述标题；可用 `\n` 手动断行。

已做示例：《三门问题》—— 题眼是格式巧合「换不换」三个字对应三扇门；手法是三个细框 +「不」降到 42%；光压在第二行后面。
